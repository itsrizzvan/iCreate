These classes work together to create a dialogue and story progression system for the game. When the player interacts with an NPC, the `HubNPC` system sends the interaction to the `HubNarrativeManager`. The manager checks which dialogue is available for that NPC and whether any required previous conversations have been completed. If a valid dialogue is found, it is sent to `DialogueUI`, which displays the conversation and handles moving between dialogue lines. Each line gets its text and speaker details, such as the name, subtitle and portrait, from `DialogueLine` and `SpeakerProfile`. The dialogue can either move forward through player input or automatically after a set time, depending on the sequence settings. Once the conversation ends, the manager marks it as completed, updates the player's story progress and saves it. This also allows new conversations to become available when their requirements are met. If no story dialogue is available, the NPC can play its default ambient dialogue instead. Overall, these systems handle NPC interactions, display conversations, manage story progress and store dialogue data separately, making it easier to organise and add new characters and conversations to the game.
